# Prompts confiáveis e reutilizáveis

## Objetivos da aula

Você aprenderá a escrever instruções claras, reduzir respostas ambíguas e criar modelos de prompt que possam ser reutilizados pela equipe contábil.

## A anatomia de um bom prompt

Um prompt profissional deve informar cinco elementos:

1. **Papel:** qual perspectiva a ferramenta deve adotar.
2. **Tarefa:** o que precisa ser produzido.
3. **Contexto:** regras, período e finalidade.
4. **Formato:** campos, tabela ou estrutura esperada.
5. **Critérios de qualidade:** o que fazer quando faltar evidência e como sinalizar dúvidas.

Exemplo:

> Atue como assistente de revisão contábil. Analise somente os lançamentos fornecidos. Para cada linha, retorne descrição padronizada, categoria sugerida, confiança de 0 a 1 e justificativa curta. Não invente documento ou conta. Quando a evidência for insuficiente, use status “Revisar”.

## Delimite a fonte

A instrução “use apenas os dados fornecidos” reduz o risco de a ferramenta complementar lacunas com informações inventadas. Se uma norma ou política interna for necessária, forneça a referência aprovada e peça que a resposta indique o trecho utilizado.

Nunca trate uma citação gerada como verdadeira sem abrir e conferir a fonte original.

## Prefira saídas estruturadas

Para comparar ou automatizar etapas, defina colunas ou chaves, como identificador da linha, categoria sugerida, confiança, justificativa e status de revisão.

Uma saída estruturada é mais fácil de validar do que um parágrafo longo. Também permite rejeitar valores fora da lista de categorias autorizadas.

## Use exemplos sem expor dados

Exemplos ajudam a fixar o padrão esperado, mas devem usar dados fictícios ou anonimizados. Mostre um caso normal e um caso de exceção. Evite inserir CPF, credenciais, dados bancários completos ou informações desnecessárias do cliente.

## Técnica de revisão do prompt

Antes de executar, pergunte:

- A tarefa tem começo e fim claros?
- A resposta poderá ser conferida?
- O formato está explícito?
- A ferramenta sabe como declarar incerteza?
- Foram removidos dados que não contribuem para a finalidade?

## Exercício prático

Transforme “Classifique meu extrato” em uma instrução operacional. Inclua uma lista fechada de categorias, um limiar de confiança e o comportamento esperado para casos duvidosos.

Uma versão adequada deve separar sugestões de decisões e impedir que um lançamento de baixa confiança siga automaticamente para exportação.

## Modelo reutilizável

> Atue como [papel]. Execute [tarefa] usando somente [fontes]. Retorne [formato]. Respeite [regras]. Não faça [proibições]. Quando [condição de incerteza], marque [status]. A saída será revisada por [responsável].

> Um bom prompt não elimina a conferência: ele torna a conferência mais rápida e objetiva.
